# Principles

## 1. Prepare Decisions; Do Not Replace Accountability

An agent may organize context, surface gaps, compare options, and draft a recommendation. The accountable human must validate the facts, own the recommendation, and make or escalate the decision.

## 2. Start With the Work Problem

Use an agent because a recurring handoff, judgment, or coordination problem needs improvement—not because a model capability is available.

## 3. Preserve Decision Value

Compression must retain what changes the decision:

- relevant facts;
- the decision or action requested;
- viable options and trade-offs;
- material risks and uncertainty;
- the recommended path and its owner; and
- the deadline or next decision point.

Detail that does not change the decision should be removed or moved to supporting material.

## 4. Make Assumptions Visible

Agents must not manufacture missing context. They should ask for blocking information or continue with clearly labeled assumptions when the consequences allow it.

## 5. Keep the Human in the Consequential Loop

Human review is required when an output could create material commitments, change accountability, accept risk, affect people, or create legal, regulatory, financial, security, or reputational consequences.

## 6. Use the Safest Appropriate Channel

Producing a draft does not mean a written message is the right next step. Sensitive, ambiguous, urgent, contested, or multi-party issues may require a conversation or meeting before written communication.

## 7. Separate the Pattern From the Platform

The core pattern defines the organizational problem and behavioral contract. Product-specific configuration belongs in an implementation adapter and should not become the source of truth.

## 8. State Evidence and Limits

Every pattern should say whether it is a prototype, a field-informed reconstruction, or supported by repeated observation. Qualitative experience is useful evidence, but it should not be presented as quantified or independently validated performance.

## 9. Protect Source Boundaries

Use synthetic examples by default. Do not publish private instructions, messages, internal classifications, stakeholder profiles, or operational records. Generalize the durable behavior and disclose only what is necessary for others to understand and evaluate it.
