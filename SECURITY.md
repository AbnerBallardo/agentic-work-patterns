# Security and Sensitive Information

These patterns may be adapted to workflows containing confidential or personal information. The examples in this repository are synthetic and are not authorization to expose real organizational data to an AI service.

## Before Using a Pattern

- Confirm where prompts, inputs, outputs, and logs are stored.
- Apply your organization's data-classification, retention, access, and approved-tool policies.
- Remove credentials, secrets, personal data, customer data, and unnecessary internal context.
- Require human review for consequential, regulated, financial, legal, personnel, security, or reputational decisions.
- Test with synthetic data before connecting a pattern to a live workflow.

## Reporting Sensitive Content

If you believe the repository accidentally contains confidential, personal, or security-sensitive information, do not quote or reproduce it in a public issue. Contact the repository owner privately through the contact route available on the owner's GitHub profile.

Ordinary improvements and non-sensitive defects may be reported through GitHub issues.
